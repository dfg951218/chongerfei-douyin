# 《虫儿飞》抖音方案

《虫儿飞》童声版适合发什么视频、提示词怎么写、怎么剪。基于一段"林间草坡 + 星海 + 贴地萤火"的参考片反推,
做了差异化处理:换树、换草、加一辆 28 大杠自行车,保住质感但不撞脸。

## 成片的核心设定

- 横版 16:9,真实夜景质感,无月亮入画
- 深蓝 + 青绿,草坡占画面 2/3,天空占 2/5
- 星空要密,萤火虫贴草面
- 运镜慢到几乎察觉不到
- 唯一的人迹:树下那辆旧自行车

## 一句话

感觉来自"草地发光 + 星海 + 贴地萤火 + 仰望视角",这四样不能动;
差异来自"树种、草种、人迹、运镜细节",这四样必须动。
